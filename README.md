# হাদিস ভিডিও প্রজেক্ট (সহীহ বুখারি, হাদিস নং ২: ওহী কিভাবে আসত)

টাইমস্ট্যাম্প ও অডিও থেকে ১০৮০×১৯২০ (৯:১৬), ৩০ fps অ্যানিমেটেড ভিডিও বানায়।
HTML/CSS/JS অ্যানিমেশন → Playwright দিয়ে ফ্রেম ক্যাপচার → FFmpeg দিয়ে MP4। সবকিছু GitHub Actions-এ রেন্ডার হয়।
ভিডিওর দৈর্ঘ্য ৯১ সেকেন্ড (শেষ টাইমস্ট্যাম্প ৯০.০২ সেকেন্ড, উপরের পূর্ণ সংখ্যায় গোল করা)।

## ফাইল তালিকা

| ফাইল | কাজ |
|---|---|
| `index.html` | পৃষ্ঠার কাঠামো, স্ক্রিপ্ট লোড করে |
| `style.css` | সব স্টাইল ও ফন্ট স্ট্যাক |
| `art.js` | সব SVG ভেক্টর আর্ট (বই, ঘণ্টা, বরফের কণা, ফোঁটা, গম্বুজ, পাহাড় ইত্যাদি) |
| `scenes.js` | টাইমলাইন ইঞ্জিন, ব্যাকগ্রাউন্ড, সাবটাইটেল, ১২টি দৃশ্য (প্রতিটিতে একাধিক ধাপ), `window.renderAt(t)` |
| `lines.js` | `timestamps.txt` থেকে তৈরি (render.js নিজেই নতুন করে লেখে) |
| `render.js` | ক্যাপচার + এনকোড |
| `package.json` | নির্ভরতা: playwright |
| `timestamps.txt` | আপনার টাইমস্ট্যাম্প ফাইল, অপরিবর্তিত |
| `audio.mp3` | আপনার অডিও, অপরিবর্তিত |
| `app-icon.jpg`, `google-play-badge.jpg` | অ্যাপ আইকন ও স্টোর ব্যাজ |
| `.github/workflows/render.yml` | GitHub Actions workflow (একমাত্র সাব-ফোল্ডার) |

## রেন্ডার করার ধাপ

1. GitHub-এ একটি নতুন repository খুলুন এবং সব ফাইল আপলোড করুন। `.github/workflows/render.yml` ঠিক ওই পাথেই থাকতে হবে।
2. **Actions** ট্যাব → **Render hadith video** → **Run workflow**।
   - প্রথমবার `test_seconds` = `10` দিয়ে চালিয়ে দেখে নিন। খালি রাখলে পুরো ভিডিও হবে।
3. রান শেষ হলে রানের পাতার **Artifacts** অংশ থেকে `hadith-video` ডাউনলোড করুন (ভেতরে `hadith-video.mp4`)।

## সময় বা লেখা বদলাতে চাইলে

- `timestamps.txt` সম্পাদনা করে workflow আবার চালান। সাবটাইটেল ও দৃশ্যের সময় দুটোই এখান থেকে আসে।
- ফাইলটি SRT ধাঁচের (`00:00:05,000 --> 00:00:15,000` ও নিচে লেখা) অথবা `শুরু | শেষ | লেখা | ইমোশন_ট্যাগ` ধাঁচের (সেকেন্ডে) হতে পারে।
- সময় বদলালে দৃশ্য নিজে থেকে সরে যায়, কারণ আইকন ও কার্ড সাবটাইটেলের শব্দের সাথে বাঁধা।
- লাইনের সংখ্যা বাড়ালে বা কমালে `scenes.js`-এ লাইনের নম্বর (`ls(0)`, `ls(1)` …) মিলিয়ে নিতে হবে।
- ইমোশন ট্যাগ না থাকলে `render.js`-এর `DEFAULT_TAGS` ব্যবহার হয়। এটি গ্লো-এর রঙ ঠিক করে।

## নিজের কম্পিউটারে দেখা (ঐচ্ছিক)

- `node render.js --lines` শুধু `lines.js` নতুন করে লেখে।
- `node render.js --still 3,12.5` দেওয়া সময়ের PNG স্টিল বানায় (`npm install` ও `npx playwright install chromium` লাগে)।
- ব্রাউজারে `index.html?play` খুলে একবার ক্লিক করলে অডিও সহ প্রিভিউ চলে। এটি রেন্ডারে ব্যবহার হয় না।

## জেনে রাখুন

- `audio.mp3` ফাইলটি আসলে WAV ফরম্যাটের (নাম `.mp3`)। FFmpeg ভেতরের ধরন দেখে চেনে, তাই কোনো সমস্যা নেই।
- অডিওর দৈর্ঘ্য ৯০.০৮ সেকেন্ড, ভিডিও ৯১ সেকেন্ড। বাকি অংশ নীরবতা (`apad`) দিয়ে ভরা হয়।
- ফন্ট `render.yml`-এ `apt` দিয়ে বসানো হয়: Noto Serif Bengali, Amiri ইত্যাদি। ফন্ট ফাইল সাথে দেওয়া হয়নি।
- হাদিসের আরবি পাঠ, নাম ও সম্মানসূচক বাক্য আরবি হরফে, পূর্ণ হরকতসহ লেখা। কোনো নবী বা সাহাবির মুখ বা শরীর আঁকা হয়নি।
